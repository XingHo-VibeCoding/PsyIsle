# 心汐 · XinXi

**一款温暖治愈的大学生心理陪伴 App —— 给「空心」的人一个出口、一盏灯、一个每天在的伴，帮他们找回与自己的连接。**

> 现行产品定义：[`PRD.md`](PRD.md) v5.0 ｜ 技术方案：[`TECH_DESIGN.md`](TECH_DESIGN.md) v3.0 ｜ 需求研究：[`research.md`](research.md)

## 它在做什么

| 模块 | 解决什么 | 包含 |
|---|---|---|
| **倾诉树洞** | 我想说，但没人听 | AI 聊天倾听 ｜ 匿名社区（发帖 / 点赞 / 举报） |
| **指路灯** | 我不知道该往哪走 | 测评（只给描述，不给分级）｜ 行动小任务 ｜ 书影音推荐 ｜ 主题多选 |
| **日常管家** | 每天有人在 | 心情打卡 ｜ 记录一个小进步 ｜ AI 陪你复盘 ｜ 全部可定制 |

三个模块都能单独用，也都共享同一个求助入口。

## 三条不能破的底线

1. **危机入口常驻**：任意页面 ≤1 次点击可达，号码打包进构建、断网可用。**永久不可砍。**
2. **不宣称疗效、不诱导自诊**：禁「治疗 / 疗愈 / 治愈 / 改善抑郁 / 缓解症状 / 替代就医」；不给总分、不给分级、不给百分位。
3. **压力机制默认关闭**：连续天数 / 中断提醒 /「你已落后」类提示**默认全关**，用户想开才开。这条来自真实使用者的体验，是本产品最重要的差异化。

## 发布前检查（Day 25 起）

```
node scripts/verify-project.mjs --with-build
```

一条命令过 15 项检查（密钥没进仓库 / 构建能过且产物不旧 / 环境变量真内联了 / 子路由 fallback 齐全 / 公网探活 / 跨域白名单 / 接口字段形状 / 错误不外泄 / 写入幂等 / 软删生效 / PATCH 清空真生效 / 并发不重复 / 线上跑的是本地这份产物 / 危机入口常驻 / 文档链接没失效），逐项给 PASS/FAIL 和证据，有 FAIL 退出码为 1——**有 FAIL 就不要发**。

- 检查项全部来自本项目踩过的坑，逐项的命令 / 通过标准 / 踩坑出处见 [`skills/verify-project/SKILL.md`](skills/verify-project/SKILL.md)
- 每次实跑的报告落在 `skills/verify-project/runs/`，和上一次对照就知道有没有退步
- 它给不出证据的三件事（收回 anon 写授权 / 恢复 RLS / 检查台加权限）会在结尾打印提醒，需要人确认，不算通过
