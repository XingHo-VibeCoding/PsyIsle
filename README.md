# 心屿 · Xinyu

一座安放心绪的小岛：涨知识（心理学干货科普）、缓情绪（深夜 emo 有处可去）、认识自己（4 个业界公认心理量表）。

- **面向人群**：20 岁上下、有情绪困扰甚至存在心境障碍的大学生（不分性别，女生居多）
- **安全底线**：不提供医疗诊断与治疗、不宣称疗效、不诱导自诊；每页均有危机资源入口
- **危机资源页**：不依赖任何单一学校，给出**大众可免费获取的公共资源**——首屏 120 / 110 / **12356 全国统一心理援助热线**，其余按**全国**（12356 / 12355 青少年 / 12338 妇女维权 / 12320 卫健）、**地区**（8 条 24 小时热线样例）、**面诊**（精神科与心理科之分、学生医保、转诊单）三段分类，每个号码标适用场景与服务时间；**不申请定位权限**
- **测评**：大五人格（IPIP-NEO-120，含 30 侧面）+ 自我价值感 + 自我效能感 + 思考风格 + 情绪自评，**全部免费、不用登录，免登录就能做完并拿到详细解读**
- **结果口径**：4 个量表**均无中文常模**，因此结果页**只做描述性解读**——不给分数、不给百分位、也**不给「偏低 / 中等 / 偏高」**（没有参照群体就划档位，等于编数据；且可能当场伤到状态差的用户）
- **量表版权**：只用授权明确的——IPIP（公有领域）、罗森伯格自尊量表（遗属授权免费）、一般自我效能感量表（作者授权免费）、认知需求量表（作者授权限非营利教育）。**BFI-2 / ECR-R / UCLA 孤独感 / WHO-5 等受限量表一律不用**（详见 `PRD.md` 第 5.2 节）
- **调性**：温暖治愈（奶油底 + 蜜桃橙 + 雾绿，圆角、留白、字体温柔）
- **技术路线（v2，2026-09-23 改云端全栈）**：React + Vite 前端 ｜ CloudBase 云函数（Node.js）后端 ｜ CloudBase PostgreSQL 数据库 ｜ CloudBase 静态托管部署。**数据从哪来、到哪去**：从用户手指来，经云函数写进 PostgreSQL，**每行数据只挂在她的匿名 uid 上**；前端拿回原始答案**现算现渲染**——服务端永远不存总分、档位、解读（详见 `TECH_DESIGN.md` v2.0）
- **安全设计的四条规矩**：① 前端永远不传 uid（云函数从登录态取，防伪造）；② 服务端没有诊断性字段（不诱导自诊的红线落到数据层）；③ 危机页号码打包进前端构建，**断网也照常可用**；④ 固定文案永远固定，服务端没有生成文字的代码路径
- **路线变更记录**：v1.0 曾为纯静态（HTML + 原生 JS + localStorage + GitHub Pages，commit `f0f4033`），2026-09-23 老板拍板改云端全栈。变更代价与论证见 `云端方案对比与影响评估.md`；对 PRD 的 8 处影响清单见 `TECH_DESIGN.md` v2.0 第 11 节（PRD v5.0 重写排队中，排期 25 → 约 39~47 天）
- **登录策略（2026-09-23 拍板）**：默认匿名登录（打开即用、无注册界面）+ 关于页可选绑定后跨设备
- **零基础友好（约束随路线更新）**：v1.0 九条硬约束中八条随云端路线放宽（框架/构建/npm/第三方库/异步/后端等），**「不写手绘 SVG」保留**；新增软约束「单文件尽量 ≤ 200 行，超了拆组件」、硬规则「`.env` 与数据库凭据永不入库」
- **首页是分区首页**：按使用状态分三区，「现在有点难受」（呼吸/安慰卡/求助）｜「想弄明白自己」（测评/认知纠正）｜「想看点东西」（文章）。第一屏只放第一区
- **上线方式**：CloudBase 静态网站托管（v1.0 曾定 GitHub Pages，随云端路线一并更换）

## 不该上传的文件（.gitignore 已自动拦截）

| 类别 | 例子 | 为什么 |
|---|---|---|
| 环境配置 | `.env` | 以后第 23 天存数据库地址和密码 |
| 密钥证书 | `*.pem` `*.key` | 泄露等于把家门钥匙挂上公网 |
| 依赖目录 | `node_modules/` | 体积巨大，有 package.json 就能重装 |
| 本地数据库 | `*.db` `*.sqlite` | 本地测试数据，不属于源代码 |
| 日志/系统/编辑器 | `*.log` `.DS_Store` `.vscode/` | 杂物，无共享价值 |
