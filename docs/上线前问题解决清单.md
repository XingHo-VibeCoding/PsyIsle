## 九、并行会话互相冲文件 / 一半提交（🟡 流程风险）

**问题与根因**：多会话共享同一工作区，别的会话为「交付干净」会主动 `checkout` 掉你未提交的改动，甚至 `git add -A` 扫进新 import 却不带组件文件 →「一半提交」（已造成 `2e8c417`）。

**解决方案（流程规则，已立）**
- 改动**验证通过就立刻按路径限定提交**（`git add <文件>` + `git commit -F msg -- <同样文件>`），不要攒着等拍板。提交是本地、可回退；不提交才会真丢。
- 提交前 `git status --short` 核对暂存内容，只 add 自己的文件；用 `git diff <文件>` 确认改动还在（可能被对方回退）。
- 收尾前两边核：`git show HEAD:<文件>` 与工作区一致、新引用文件 `git ls-files --error-unmatch` 确实被跟踪。
