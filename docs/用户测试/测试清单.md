# 心汐 · 轻量用户测试清单

> 用途：找一位真人（不认识这个项目的人最好），照下面走一遍，记录他**卡在哪一步**。
> 适用日：Day 14 起，往后每做一轮真人测试都可以复用。
> 记录文件另存 `记录/YYYY-MM-DD-DayN-记录.md`，本文件只放"怎么测"，不改动、不写结果。

---

## 0. 开场语（照念，别多做解释）

> "这是一个还在做的小东西，我想请你随便用用，看看哪里会让你卡住。
> 没有对错——卡住了不是你的问题，是我没做清楚。你卡在哪一步，对我来说就是最有用的信息。
> 我会在旁边记，你可以边点边把想法说出来，不想说也没关系。"

**三条禁令**：
- 不介绍功能、不解释产品是干什么的（一解释，测的就不是页面了）。
- 他问"这是干嘛的" → 只回"你觉得呢？"（先接住他自己的理解，记下来）。
- 他卡住时不要指路，先等 15 秒，等他开口说"这里是什么意思/我该点哪"。

## 2. 任务清单（一个一个来，做完一个停一下）

给测试者的原话写在"任务"列，**逐字念，不加提示**。

| # | 任务（原话） | 想看什么 |
|---|---|---|
| T1 | "先随便看看，然后跟我说一句：你觉得这是干什么用的？" | 首屏能不能自解释；他第一眼看到的是什么 |
| T2 | "假设你今天心里有点堵，想找个地方说说话。你会点哪里？" | 三扇门的名字/图标看不看得懂；点到「听你说」发现是"还没做完"时的反应 |
| T3 | "帮我找一件今天就能做的小事。" | 能不能找到「找方向」；主题筛选与"行动小事"的关系看不看得懂 |
| T4 | "再帮我找本轻松的书，或者一部电影看看。" | 能不能发现子导航（书影音）；会不会以为页面到底了 |
| T5 | "如果你现在特别难受、撑不住了，想马上找个能打的电话——你会去哪找？" | **红线**：危机入口是不是 1 次点击可达、好不好找 |
| T6 | "你想知道这东西是谁做的、你在上面写的东西存哪了，去哪看？" | 页脚 / 关于页能不能被发现 |

## 3. 每个任务记这 4 项

1. **完成了吗**：自己完成 / 提示后才完成 / 没完成
2. **卡在哪一步**：具体到"哪个字、哪个按钮、哪一屏"（不要写"有点困惑"这种含糊话）
3. **点什么 / 几次**：他先点了哪里，点了几次才到；有没有反复横跳
4. **原话**：他说出口的话**照抄**（比如"这个'找方向'我以为是导航"——原话比总结有用）

> 记录员（我）不评价、不辩护。他不是来夸这个产品的。
