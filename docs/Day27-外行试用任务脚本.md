# Day 27 · 外行试用任务脚本（心汐）

> 用途：找一位**没参与过项目**的真人，在他自己的设备上走完核心流程。
> 用法：两条横线之间的内容**整段复制发给他**，不要补一句解释；你自己拿着《Day27-试用记录表.md》在旁边记录。
> 链路设计：打开公网链接 → 看到核心数据 → 完成一次核心操作（打卡）→ 刷新确认 → 修改 → 删除。
> 脚本里**故意有两处说得含糊**（第 3、5 步）——他卡在那里，正是今天最想要的信息，别提醒。

---

帮我个忙，大概 5 分钟 🙏

我在做一个网页小东西，还在做、还很粗糙。想请你当第一个用户用一遍，看看哪里会让你卡住。

**卡住不是你的问题，是我没做清楚**——你卡在哪一步，对我来说就是最有用的信息。

请在你自己手机上用浏览器打开（第一次会慢一点）：

https://psyisle-prod-d9g109suw53257aed-1506897881.tcloudbaseapp.com/

一边用一边把想法随口说给我（打字、语音都行）。按顺序做这几件事，每做完一件停一下：

1. 先打开看看，然后跟我说一句：你觉得这是干什么用的？
2. 找到首页上能「留下点什么」的地方，点进去，看看里面已经有什么。
3. 在上面找个地方，把今天的心情记下来——想写什么写什么，写多写少随你。
4. 记完别退出，刷新一下页面（或者关掉重开），看看你刚记的那条还在不在。
5. 想想刚才那条记录——如果想改几个字，你会怎么办？照你的办法做。
6. 把刚记的那条删掉，确认它从列表里消失了。

最后拍一张**你手机屏幕的照片**发我（要能看清页面上的内容）。

不用都做完，做到哪算哪；不想做了随时停，跟我说一声就行。

## 主持纪律（给你自己，别发给对方）

- **不解释**产品是干什么的；**不指路**——他问「点哪」就说「你觉得呢」。
- 他卡住**先等 15 秒**，等他先开口；一开口就记**原话**，别转述。
- 两处故意含糊的地方：**第 3 步**（没说要先点一个表情）、**第 5 步**（没说怎么改）。卡住＝收获，不是失败。
- 屏幕上弹出任何没让他点的东西（比如「你写下的东西，现在只有这台设备能打开」），都不提示，让他自己处理，记下他选了哪条、当时说了什么。
- 已知预期（不是 bug，别在现场"修"）：新访客名下没有任何记录，首页不会出现「最近一次」一行，列表是空的——重点看他读不读得懂空状态，并完成第一次记录。
- 他要是点进了「听你说」，会看到占位页「这个页面正在按任务排期逐个上线」——记录他的反应，别解释。
