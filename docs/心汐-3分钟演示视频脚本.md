# 心汐 · 3 分钟演示视频脚本

> 用途：课程第 28 天结课演示 / 对外展示。配套线上环境：`https://psyisle-prod-d9g109suw53257aed.tcloudbaseapp.com`
> 重要：该域名为腾讯云测试域名，**首次打开会有风险提醒页**，需点「确定访问」（按钮有 3 秒倒计时），点完才进应用。录屏时第一镜就把这一步录进去，或提前点好再开录。
> 原则：**只演示真实可用的功能，不吹没做好的**。倾诉树洞（听你说）目前是「建设中」页，如实带过即可。

## 设备与设置
- 用 Chrome/Edge 全屏录制，窗口 1280×800 以上，录系统声音或旁白。
- 录前先手动开一次应用（过风险页 + 等首屏数据加载完），避免录到加载转圈。
- 演示账号是「固定演示身份」，写入的数据是全站共享的演示数据——**别写真实隐私**（金额、姓名、健康细节）。

## 0:00–0:20 片头：为什么做这个（20s）

- 画面：浏览器打开 `https://…tcloudbaseapp.com/`，过风险页，停在首页 `/`。
- 旁白（口语）：
  > 这是我用 28 天 vibe coding 做出来的一个大学生心理陪伴小应用，叫「心汐」。它不宣称能治病，也不让你做心理测评打分——它只做三件事：日常管家、指路灯、倾诉树洞。今天用三分钟带你真实走一遍，所有数据都是真接口、真落库的。

## 0:20–0:55 日常管家 `/daily`（35s）—— 核心功能，重点演示

- 画面：`/daily`，展示「今天的情绪胶囊」列表 + 「记一件小进步」输入区。
- 操作（边做边说）：
  1. 选一个情绪（如「平静」），强度选 3，附言写「今天把拖延的作业开了个头」。
  2. 点「保存」→ 列表立刻出现这条；上方情绪胶囊刷新。
  3. 在「小进步」输入框写「把袜子洗了」，点保存 → 下方小进步列表新增一条。
- 旁白：
  > 日常管家是我做得最完整的一块。它不要求你每天打卡、不打分排名——你今天想记就记。情绪可以打分也可以只选一种心情，小进步甚至不用努力到「值得记」。写入之后列表会自己刷新，因为后端是真的把这条存进了数据库。

## 0:55–1:30 指路灯 `/guide`（35s）

- 画面：`/guide`，展示任务清单（TasksView）与素材库（LibraryView）两个子页，用顶部 Tab 切换。
- 旁白：
  > 指路灯负责把「我想变好」拆成今天能做的一小步。左边是任务清单，右边是素材库。它的设计刻意避开打卡和排名——因为很多人（包括我自己）一看到「连续天数」「超过别人」就会产生羞耻感然后逃跑。所以这里没有进度条焦虑，只有「今天挑一件小事做」。

## 1:30–1:50 倾诉树洞 `/talk`（20s）—— 诚实带过

- 画面：`/talk` 是「建设中」占位页。
- 旁白：
  > 倾诉树洞这块我还没做完，是个建设中页面。我没硬塞一个半成品进去——产品节奏是先把自己当用户体验，真觉得哪一步有用再补。这也算 28 天里学到的一课：别为了「看起来完整」提前承诺。

## 1:50–2:25 检查台 `/check`（35s）—— 证明不是假数据

- 画面：`/check`，展示健康状态、moods / 小进步的真实条数、最后更新时间、以及一个写入测试入口。
- 操作：在检查台点一次「写入测试」→ 看返回 ok:true 和刷新后的条数。
- 旁白：
  > 这个检查台是给后端做真实验证用的：它直接读数据库里的真实条数，也能现场发一次写入请求。你看它回的是 ok:true，说明前面那些界面背后是真接口，不是写死的假数据。

## 2:25–2:50 危机入口 `/help`（25s）—— 安全红线

- 画面：`/help`，展示心理危机热线号码（如 12356），号码是可点击拨打的。
- 旁白：
  > 这是全站不可删的一条红线：无论你在哪个页面，最多一次点击就能到达危机热线。我们不诱导自诊、不分级打分，遇到真的危急情况，直接给能求助的号码。这是产品底线，写死在导航和页脚两处。

## 2:50–3:00 收尾（10s）

- 画面：回到首页 `/` 或 About。
- 旁白：
  > 28 天下来，心汐从一行想法变成了真能用的三合一陪伴应用。下一步我会接登录，把数据按人隔离、把检查台也加上权限。谢谢大家。
