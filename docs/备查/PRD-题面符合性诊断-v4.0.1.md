## 二、4 处缺口的处理详情

### 缺口 ①：MVP / 加分 / 后续三级分级（新增第 5.0 节）

**原问题**：13 个功能全标 P0，文档失去「先做什么」的能力。

**处理**：新增第 5.0 节，用一张表辨析「**加分项 ≠ 可降级**」：

| 概念 | 含义 | 态度 |
|---|---|---|
| 可降级（禁止） | 「做不完就算了」——无边界 | ❌ 仍然禁止 |
| **MVP**（7 项） | **上线门槛**，缺一项就不该上线 | ✅ 新增 |
| **加分项**（8 项） | **有明确放弃条件**的锦上添花 | ✅ 新增 |
| 后续 | 第 9 节逐条给了边界 | ✅ 已有 |

**MVP 7 项**：F11 分区首页 / F12 危机资源页 / F1 大五测评 / F6 情绪自评 / F7 呼吸练习 / F8 随机安慰卡 / F9 认知纠正。每项都写了「为什么它是门槛而不是加分」。

**没有恢复「可降级」**——这是关键区别：加分项是「会做，做不完才砍」，有明确条件；可降级是「做不完就算了」，无边界。

### 缺口 ②：异常状态（新增第 8 节，18 条）

**原问题**：题面点名要求，全文无此章节。已散落存在 6 条，从未写过 12 条。

**处理**：新增第 8 节，18 条分四类：

| 类 | 条数 | 举几条从未写过的 |
|---|---|---|
| 本地存储类 | 7 | localStorage 不可用（Safari 无痕）、写满 `QuotaExceededError`、JSON 损坏、结构版本不匹配 |
| 浏览器环境类 | 3 | **禁用 JavaScript**（须写 `<noscript>`）、被分享给他人打开、浏览器版本过旧 |
| 使用中断类 | 4 | 呼吸练习中来电、长按/双击/误触 |
| 内容安全类 | 4 | 危机关键词、安慰卡连点、自评 crisis、**号码已失效**（需人工核实） |

**关键点**：这 18 条**必须有人去实现**，所以拆出了 **T13b** 任务（任务 24 → 25）。**这也是一次自检**——如果拆不出单日任务，说明第 8 节写得太空。拆得出来，说明它是实的。

### 缺口 ③：交互要求（新增第 6.2 节，六类）

**原问题**：交互要求散落在各功能验收标准里，没有通用清单，每个页面各写各的。

**处理**：新增第 6.2 节六类：A 点击与反馈 / B 等待与进度 / C 返回与导航 / D 表单与输入 / E 动画与降级 / F 键盘与无障碍。

其中一条值得单独说：**「无需加载态——本站无异步请求，不设 loading 转圈，出现转圈说明设计错了」**。这条把「零基础实现」落成了一个可观察的现象。

### 缺口 ④：「分区首页」（F11 重写）

**原问题**：题面要求「分区首页」，原 F11 只是一排功能卡。

**处理**：F11 改为「分区首页」，按**使用状态**分三区：

| 区 | 标题（用户视角） | 放什么 |
|---|---|---|
| 一 | 「现在有点难受」 | 呼吸练习、安慰卡、危机资源入口 |
| 二 | 「想弄明白自己」 | 测评总览 + 认知纠正 |
| 三 | 「想看点东西」 | 4 篇知识库 |

**为什么按状态分而不是按功能类型分**：目标是深夜 emo 的人，她此刻不是来「浏览功能」的，是按当下状态找出口。按功能类型分区要求她自己判断「我该用哪个工具」——**她判断不了，那正是她此刻的状态**。

**新增硬约束**：分区标题**禁用**「应急 / 探索 / 深度 / 模块 / 板块 / 专区」六个词（内部术语，用户看不懂）。

**这个改动与已有的「板块预期」表天然咬合**——那张表本来就在第 9 节躺着，只是没搬到首页。
