## 2. 部署步骤（三条，顺序不能乱）

```bash
# ① 两个云函数，一次只发一个（连发会被 120s SIGTERM 打断），每个给 300s
tcb fn deploy moods -e psyisle-prod-d9g109suw53257aed --dir cloudfunctions/moods \
  --force --deployMode zip --install-dependency true
# 等完再发第二个
tcb fn deploy notes -e psyisle-prod-d9g109suw53257aed --dir cloudfunctions/notes \
  --force --deployMode zip --install-dependency true
```

```bash
# ② 前端：build 会清空 dist，再补子路由入口，最后才是托管部署
npm --prefix frontend run build
node scripts/spa-fallback.mjs
tcb hosting deploy frontend/dist -e psyisle-prod-d9g109suw53257aed --verify
```

⚠️ 三条老坑，缺一条就出事：

- `--force` **必加**（本环境非 TTY，不加会卡在交互确认）
- **不加** `--httpFn`（会改函数类型、打断 HTTP 访问路径）
- `spa-fallback.mjs` 必须**在 build 之后**跑（build 会清掉 dist 里的子路由入口）
