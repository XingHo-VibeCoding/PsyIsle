01 设计背景 Background 切入点不是笼统的「心理健康」，而是一个具体的状态
问题定义

「说不清哪里不对，就是觉得一切没意思」——而手机里没有一个地方能安放这种状态。

它看起来像抑郁，但不是。北京大学徐凯文教授 2016 年提出的「空心病」指向的是价值观缺失：内心空虚、无意义感、对未来没有期待、对当下缺乏热情——三重特征是空心理 / 空理想 / 空价值。

这个区别决定了产品做什么、不做什么：它不该是一台判断你「有没有病」的机器，而是一个能待着的地方。

调研依据
30% +

大学生「空心病」比例已突破 30%，中学生接近 50%，且逐年上升。

覆盖 152 所高校、453 万大学生 + 7 万中小学生。

来源：北京大学徐凯文团队十年调研（2016 起）。此处仅作设计背景引用，不构成任何诊断标准；心汐不提供诊断。

02 三条不能破的底线 Non-negotiable 写在 README 里的三行，也是本项目设计决策的裁决顺序：保护用户 > 课程要求 > 开发效率
01

危机入口常驻

任意页面 ≤1 次点击可达，号码打包进构建、断网可用。永久不可砍。

视觉落点：导航最右常驻「求助」、页脚兜底，首页由浮动导航承担。危机页只用平静色。

02

不宣称疗效、不诱导自诊

禁「治疗 / 疗愈 / 治愈 / 改善抑郁 / 缓解症状 / 替代就医」；不给总分、不给分级、不给百分位。

量表的措辞走「描述」而不是「评判」：情绪强度的 1–5 明确是「这股感觉有多强」，不是好坏打分。

03

压力机制默认关闭

连续天数、中断提醒、「你已落后」类提示默认全关，用户想开才开。

这条来自真实使用者的体验，是本产品最重要的差异化——同行都在用连续天数，而这对这群人恰恰最有害。

03 四条视觉纪律 Principles 违反任何一条，视觉就会从「治愈」滑向「花哨」
01

装饰退到内容后面

装饰性渐变只出现在首页插画与图标柔光里，页面里不允许出现第二个装饰区。

02

装饰不承载信息

小角色只陪伴不功能：不说话、不传状态、不可点、不进无障碍树；同屏最多一只。

03

越紧急越要稳

危机页只用夜森林绿。全站禁红色警示色是产品级红线——没有一种语义状态用红色表达。

04

信息宁少勿多

一张卡只说一件事；能靠留白分开的就不加分隔线；新增内容先问能不能删掉一条旧的。

气质

小王子的夜空

视觉上对应三样东西：森林深处那样安静的一层绿、插画里那点星光的暖黄、一只陪着你的小角色。

  • 只有两族色：夜森林绿管动作与安抚，淡紫只做冷调点缀。
  • 旧的暖色整套退役：蜜桃橙、暖米白、暖调描边一律不得再出现。
  • 同屏只有一套动作色：出现两套会被读成两种状态。
05 三个模块 Modules 三个模块都能单独用，也都共享同一个求助入口
1

倾诉树洞

「我想说，但没人听」

  • AI 聊天倾听 —— 不做导流，只做倾听
  • 匿名社区：发帖 / 点赞 / 举报
  • 无关注、无好友、无排行
产品内入口：听你说
2

指路灯

「我不知道该往哪走」

  • 测评：只给描述，不给分级
  • 行动小任务 13 件 · 书影音 18 条
  • 主题多选：勾几个都行，一个不勾也行
产品内入口：找方向

「每天有人在」

  • 心情记录：7 个情绪，可空着不写

06 界面展示 Interface 均为本项目实际运行画面，非效果图
07 设计价值 Value 差异化落在三处，而不是「功能更多」
01 切口

「空心」这个具体状态

不做笼统的心理健康平台。先认下一个人此刻的那句话，再决定给什么。

02 反常识

把压力机制默认关掉

同行都在用连续天数做黏性，而比较本身就是这个人群的病灶。没有 streak、没有排行榜、没有「你已落后」。

03 一等公民

求助资源是功能，不是免责声明

常驻导航、断网可用、页面不隐藏、不可砍。越紧急越平静——所以危机页不用红色。

主动不做的事（每一条都是研究后认真放弃的，不是忘了）
  • 咨询撮合 · 会毁掉「不导流」的定位
  • 付费报告 · 「免费且完整」是卖点
  • 私信 / 关注 / 好友 · 把倾诉变成表演
  • 排行榜 / 连续天数 · 比较即病灶
  • 白噪音 / 睡眠故事 · 重内容运营，做不起
  • 心理 FM / 播客 · 制作成本高
  • 会员 / 广告 / 引流 · 会破坏信任
  • 多语言 / 小程序 / 原生 · 聚焦手机 PWA
